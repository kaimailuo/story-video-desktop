# 映序：本地视频工作台

面向 **Intel Mac（x64）** 的桌面视频原型。独立实现文案、分镜、素材和 MP4 导出流程，不包含参考产品的代码、品牌素材或授权绕过。

- **[功能总清单与实现进度](docs/FEATURES.md)**：完整功能范围、逐项状态、验收标准、当前限制和变更记录；后续持续维护，以此为准。
- [实施路线](docs/ROADMAP.md)：阶段划分与建议实施顺序。

## 当前范围

- 故事解说、小说推文、知识解说三类示例文案；共用同一套本地制作引擎。
- 按句子拆分分镜，编辑字幕、时长，调整分镜顺序。
- 本地拆分／采用 AI 分镜一律确认替换影响，可撤销最近一次分镜替换；仅本次会话有效，关闭／切换项目失效，不删除磁盘素材。
- 单张／批量导入图片，导入全片配音和背景音乐。
- 静态或缓慢推进运镜、直接切换或淡入淡出。
- 横竖屏、720p／1080p，导出 H.264 + AAC MP4。
- 渲染进度、取消任务、失败清理。成功前不替换已有目标文件。
- JSON 项目保存与打开；项目引用原始素材的绝对路径，**不打包素材**。
- 素材统一检查：聚合图片／配音／音乐及启用字幕的阻塞与警告，定位分镜；MP4 导出前重新检查，阻塞不开始渲染、不覆盖旧成片。
- 内置 9 秒演示项目，无需 API Key 即可验证出片。
- 文本模型配置与连接测试；可配置 OpenAI 兼容聊天接口，不预设供应商。
- AI 改写与结构化分镜：先预览候选再采用，可编辑画面描述／绘图提示词，保留最近 100 条已采用改写的原文和结果。
- 超时、取消、认证／限流提示；不自动重试、不跟随重定向，避免隐藏调用。
- 取消覆盖保存检查点的准备阶段：尚未提交时不发送生成请求；已提交后不能保证服务端停止计费。
- 独立图片模型配置、单镜／缺图批量／全片重新生图；逐张候选采用或丢弃，每镜保留最近 20 个图片版本引用。
- 图片生成逐镜串行，支持进度、取消和部分成功保留；认证失败、限流或落盘失败停止后续调用。
- 独立配音模型配置、音色／语速、单镜／缺失或过期批量配音；候选先试听再确认采用，按实际 WAV 时长同步镜头。
- 全片／按镜配音显式切换，不重复混音；按镜缺配音处静音，文字过期或镜头短于音频时阻止导出。
- 图片／配音每镜保留最新成功候选和最近失败；失败不挤掉成功，新成功替换同镜旧候选／失败，未采用候选不随项目恢复。
- 每镜最多 20 条独立字幕，可编辑起止时间、按帧静态预览、保存草稿并按时烧录；支持独立 SRT 导出。初始化只是长度估算，不是语音对齐。
- `0.6.0`：编辑后约 0.6 秒保存独立草稿，启动可查看、恢复或放弃；记录任务状态及已完成产物，支持大小／SHA-256 核验，不自动重发生成请求。
- 任务图片／有原稿元数据的配音可核验预览、明确选镜并确认关联，采用前再次复核；不删除旧文件或调用模型。
- 长文先预览分段与请求上限，再串行处理；逐段结果随项目保存，失败停止、成功不重发，补跑需确认；来源编号完整不等于语义无遗漏。

**尚未实现：**语音字幕对齐、断点续跑、音乐 MV、HTML 动画、混剪、剪映草稿。文本、图片与配音 AI 已做本机模拟接口验收，**尚未联调真实模型服务，也未验收真实 macOS 钥匙串授权与解密**。图片只接受兼容接口的 Base64／同源 URL，不支持跨域 CDN；配音只接受完整 PCM16 WAV，不支持 MP3 或原生异步协议。不能将当前原型视为参考产品的完整替代品。

## 开发运行

建议使用 Node.js 22 LTS、npm，以及支持当前 Electron 的 macOS 版本。

```bash
cd /Users/kaimailuo/projects/lwj/ai/story-video-desktop
npm install
npm run dev
```

开发启动会编译桌面主进程，并在 `127.0.0.1:5173` 启动仅本机访问的 Vite 服务。前端变更可热更新；主进程与 preload 变更需要重启。

首次运行点击右下方「载入演示项目」，再点击「导出 MP4」。演示由程序生成抽象插画与合成音调，不包含真人配音，也不调用网络服务。

使用文本 AI 时，在左侧「文本模型设置」中填写基础地址、模型和 Key，保存后可主动测试。**无需提前把任何 Key 发到聊天中。** 详细操作与安全边界见 [文本 AI 配置与验证](docs/AI_SETUP.md)。如果旧客户端还开着，请先保存项目，关闭旧窗口及对应开发进程，再运行 `npm run dev`；仅前端热更新不会更新主进程和预加载接口。

使用生图时，单独填写「图片模型设置」，逐镜编辑绘图提示词，在「AI 分镜生图」面板选择尺寸并确认调用。图片先落盘为候选，点击「采用此图片」才更新分镜；可在「当前分镜图片版本」切回旧图。详细限制见 [图片 AI 配置与验证](docs/IMAGE_SETUP.md)。

使用配音时，单独填写「配音模型设置」，在「AI 按镜配音」面板填写服务商提供的音色标识与语速，确认生成后加载试听、采用。采用会切为按镜模式并同步镜头时长；原全片配音引用仍保留但不参与混音，可显式切回。详细边界见 [配音 AI 配置与验证](docs/SPEECH_SETUP.md)。

仍建议手动保存项目。自动草稿不覆盖手动文件；正常退出会尝试刷新最后编辑，强制结束可能丢失尚未写入的修改。启动后在「自动保存与恢复」选择草稿；任务产物不会自动回填，也不会自动联网续跑。操作、存储位置与边界见 [自动保存与恢复](docs/RECOVERY.md)。

「撤销最近一次分镜替换」只恢复分镜及其字幕、图片／配音引用，不恢复项目级文案或配音模式；替换后的分镜编辑会被放弃，撤销前会确认。重复分镜编号的项目会被拒绝并提示位置，不自动改编号，旧的非 UUID 唯一编号仍可打开。

任务素材重新关联：在「任务记录」选择目标分镜，点击「核验并预览关联」，核对后确认；允许显式跨工作区关联，但不会自动匹配。旧图片可作为本地导入，旧配音缺生成原稿／音色时拒绝。见 [产物重新关联](docs/产物重新关联.md)。

长文处理：点击「预览改写分段」或「预览分镜分段」，查看计划后确认处理未完成段。分镜每段最多 600、改写最多 1200 UTF-16 字符，每段输出上限 4096 Token，首错停止；可保存重开后显式补跑。覆盖只检查模型声明的原文编号，不证明语义忠实、事实正确或跨段一致。合并超过 100 镜／30,000 字符拒绝而不截断。见 [长文分段与覆盖检查](docs/长文分段与覆盖检查.md)。

导出前可在「素材统一检查」主动检查，也可直接点击「导出 MP4」触发主进程预检。闲置模式中的坏配音仅警告；缺少按镜配音仍按静音处理。项目编辑后报告过期，外部文件变化不会自动刷新；导出会重新读取。检查只读，不找回或删除文件；普通音频单项最多 30 秒，超时不算通过。范围和边界见 [素材检查说明](docs/素材检查.md)。

全片配音从片头播放，过短补静音、过长截断；按镜配音不会静默截断，缺配音处静音。音乐循环到视频结束。

旧项目字幕仍整镜显示；在右侧「字幕时间轴」可启用多条字幕、修改文字与起止秒数，使用预览游标检查条目和间隙。按镜模式以已采用配音实际时长为上限，改配音稿、配音版本或模式后需检查确认。无效草稿可保存，但烧录 MP4／导出 SRT 会拒绝。独立字幕措辞不影响配音稿；详细操作与帧规则见 [字幕时间轴与 SRT](docs/CAPTIONS.md)。

## 实现选择

- **Electron + React + 严格 TypeScript：**主进程、预加载桥及界面共用类型；比 Tauri 包体更大，但避免额外维护 Rust 层，适合先验证媒体流水线。
- **FFmpeg：**优先使用 `ffmpeg-static` 提供的本机架构二进制，开发环境可回退到已知系统路径。不拼接 shell 命令。
- **Sharp：**修正图片方向，生成字幕透明图片；无需 FFmpeg 的 libass／subtitles 滤镜。导出中文字体依赖 macOS 系统字体。
- **JSON 项目及恢复记录：**当前单窗口、串行任务采用独立 JSON、版本号和原子替换，便于排查且无新增依赖；SQLite 事务／查询更适合后续大队列，届时再评估迁移。

渲染页面禁用 Node.js，启用沙盒及上下文隔离，文件能力经固定 IPC 暴露。导入的图片和音频本地处理，不上传；文本 AI 确认后发送当前文案（分段模式仅本段）、类别和补充要求，分段还发送段序号及原文单元编号，不共享其他段正文；连接测试只发送极短消息。生图发送绘图提示词、模型及尺寸，配音发送各镜配音稿、模型、音色与语速，不发送独立字幕时间轴。无积分和账户系统。

Key 通过 Electron `safeStorage` 加密，以密文分别写入用户数据目录的 `ai-settings.json`、`image-settings.json`、`speech-settings.json`；在 macOS 上，加密所用密钥由系统钥匙串保护，**不是直接将 API Key 明文写入钥匙串条目**。地址、模型和超时为普通配置，Key 不回显、不放入项目 JSON。系统加密不可用时不回退到明文。

生成图片保存在该目录的 `generated-images/`；项目只记录绝对路径和已采用版本的提示词／模型／时间，不包含图片本体。未采用候选不随项目恢复；丢弃候选或超过版本数量上限不会删除文件。当前没有自动清理和存储配额，清理前务必确认没有项目仍在引用。

生成配音保存在 `generated-speech/`，项目保存已采用片段的路径、文字、模型、音色、语速及实际时长，不包含音频本体。替换／移除配音或丢弃候选不删文件；暂无配音版本切回、素材打包或孤立文件清理。

恢复数据位于同一用户数据目录的 `recovery-v1/`，包括草稿、任务及文本结果；它们含用户文案、本地路径及已登记图片／配音采用元数据，不包含模型服务配置或凭据，且不是加密备份。长文计划与未采用的逐段文本候选随项目／草稿保存，整体采用或丢弃后清除计划；图片／配音未采用候选仍不自动回填面板，可按任务显式关联。放弃草稿不删除文件或素材；任务面板最多显示最近 100 条，没有自动清理或存储配额。

导出测试使用真实 FFmpeg，验证横竖屏、字幕分支、音轨、编码、时长、取消和失败时已有文件保护。媒体探测测试当前使用此 Intel Mac 的 `/usr/local/bin/ffprobe`，其他环境需调整该测试路径。

`npm run demo:export` 可单独验证 720p 合成引擎，生成 `artifacts/demo-intel.mp4`、演示素材和可打开的项目文件。

`npm run test:desktop` 只编译本客户端主进程，再启动真实 Electron 窗口验证预加载桥、演示项目、保存／打开和 MP4 导出。测试自动选择 `artifacts/` 下的输出文件，不需要手动操作对话框，并保留桌面截图和成片。

`npm run test:ai-desktop` 验证真实桌面中的模型配置、改写／分镜候选、采用、历史保存／重开、错误和取消。它只调用本机临时模拟 HTTP 服务，并替换测试进程中的系统加密边界，避免触发真实钥匙串授权弹窗；不能替代真实服务和钥匙串联调。桌面测试自动选择空闲端口，不关闭已运行的开发服务。

`npm run test:images-desktop` 用本机模拟生图服务验证单镜、批量、候选过期、版本切换、部分失败与取消、保存重开和真实 MP4 导出；测试内同样替换系统加密边界。产物为 `artifacts/images-smoke.mp4`、截图与项目，不代表真实模型生成质量已通过。

`npm run test:speech-desktop` 验证真实 Electron 的配音配置、WAV 试听解码／播放、候选采用、模式与时长、过期／截断保护、部分成功、取消、保存重开和 MP4 音轨顺序／静音间隙。产物为 `artifacts/speech-smoke.mp4`、截图与项目；模拟服务返回测试音调，不是真实人声，safeStorage 为测试替身。

`npm run test:captions` 覆盖 10 项字幕核心及 4 项真实媒体测试，逐帧检查时间边界；`npm run test:captions-desktop` 验证真实 Electron 编辑、无效草稿保存重开、采用更短配音后过期／越界、排序、SRT 与 MP4。产物为 `artifacts/captions-smoke.*`，仅本机模拟素材，不做真实付费调用。

`npm run test:relink-text` 覆盖 17 项产物关联、长文规划／执行及分段协议；`npm run test:relink-text-desktop` 自行局部编译主入口与 preload，验证真实 Electron 的显式关联、文件复核、首错停止／重开补跑、覆盖异常、整体采用与准备期取消。截图为 `artifacts/relink-text-smoke.png`；仅本机模拟服务，safeStorage 为替身。2026-11-13 本轮另有 35 项相关回归（共 52 项）及素材／文本／恢复／可靠性四套旧桌面流程通过，详见功能清单 V23–V26；无全量检查／构建或安装包验收。

## 本地测试打包与安装

```bash
CSC_IDENTITY_AUTO_DISCOVERY=false npm run package:mac
```

目标为 x64 DMG，输出到 `release/`。上方命令关闭本次签名身份自动发现，不改变系统安全设置；执行客户端生产构建，首次可能下载打包资源，不安装应用或调用模型。当前 Electron 声明最低 macOS 13.0，本机测试环境为 Intel Mac／macOS 14.7，不代表所有 macOS 13 设备已验收。

构建成功不等于安装使用验收通过；安装或覆盖已有“映序”前先确认并保存工作。开发者签名、Apple 公证及自定义图标尚未配置，不能视作已可公开分发的正式版本。安装后验证范围见 [安装包构建与验收](docs/安装包构建与验收.md)。
