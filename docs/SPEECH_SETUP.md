# 配音 AI 配置与验证

## 当前范围与协议

`0.4.0` 提供独立配音模型配置、音色／语速、单镜／批量生成、候选试听与采用、实际音频时长同步以及 MP4 音轨合成。**目前仅通过本机模拟接口验收，未验证真实人声模型、实际计费或真实 macOS 钥匙串授权／解密。**

使用 OpenAI 兼容 `POST /audio/speech`：

```json
{
  "model": "用户配置的模型标识",
  "input": "当前分镜配音稿",
  "voice": "用户填写的音色标识",
  "speed": 1,
  "response_format": "wav"
}
```

服务必须返回完整 RIFF/WAVE、PCM format 1、16-bit、单／双声道、8–96 kHz 音频。单段大于 0 且不超过 60 秒，总响应不超过 24 MiB；不接受 MP3、浮点／压缩 WAV、未知长度流式 WAV、音频 URL 或原生异步任务协议。不同兼容服务对音色、语速和格式的支持仍需联调，无静默协议或模型回退。

选择 WAV 是为了直接按采样数精确计算时长、校验格式，无需新增解码依赖。备选 MP3／其他格式覆盖面更广，但需要解码及额外时长探测；原生异步接口可支持更长任务，但需另做轮询、恢复与计费适配，本轮不引入。

## 配置与使用

1. 保存项目，关闭旧客户端及其开发进程，重新运行 `npm run dev`；前端热更新不能更新主进程和 preload。
2. 打开「配音模型设置」，填写基础地址、准确模型标识、5–180 秒超时和 Key。基础地址不包含 `/audio/speech`；公网必须 HTTPS，本机 loopback 测试可 HTTP。
3. 配置与文本／图片独立，不复用 Key。保存不联网、不拉取音色列表；没有单独免费连接测试，主动生成一镜验证仍可能按正常配音计费。
4. 在「AI 按镜配音」填写服务商提供的音色标识、语速（0.25–4）。二者随项目保存，不保证每个服务支持全部语速。
5. 逐镜编辑右侧「配音稿／旧模式整镜字幕」。配音只使用该文字，不使用独立字幕时间轴、全文、画面描述或绘图提示词；单镜最多 180 字符。字幕措辞可单独编辑，不必重配音。
6. 选择「生成当前分镜配音」「批量生成缺失或过期配音」或「重新生成全部分镜配音」，确认地址、模型、音色、语速及最多调用次数。
7. 点击「加载试听」，再使用本地播放器试听。音频仅经主进程校验后以本地数据 URL 交给播放器，不直接加载远程音频；加载与播放不发模型请求。
8. 点击「采用此配音」才修改项目：按音频实际时长向上量化到 30 FPS，至少 1 秒，最长 60 秒；会替换原镜头时长，并切到按镜配音模式。如需留白，可随后手动延长镜头。
9. 保存项目再导出 MP4。字幕与候选文字不一致或分镜已删除时不可采用；仅去掉首尾空白不影响匹配。修改音色／语速不会自动让已有候选过期，采用前请核对候选显示的实际参数。

已采用配音可以再次加载试听、恢复配音时长或移除。恢复时长同样切为按镜模式；移除不恢复旧镜头时长。试听是单段音频，不是整片预览。

## 两种模式与导出

- **全片配音：**默认兼容旧项目，只使用导入的全片音频；从片头开始，过短补静音、过长截断。不使用或校验按镜配音引用。
- **按镜配音：**不使用或校验全片配音文件，但保留其路径供切回；每镜音频按镜头顺序拼接，未采用配音的镜头补整镜静音，短片段尾部补齐至镜头长度。
- 模式在配音面板显式切换。按镜模式下导入全片音频仅更新引用，不会悄悄切模式；「声音与输出」会显示全片配音当前不启用。
- 按镜导出会检查文字匹配、WAV 完整性和实际时长是否与已采用记录一致。文字改变、文件缺失／损坏或时长改变时阻止导出，需重新生成或移除。导出本身不强制检查内容哈希；`0.6.0` 任务面板可另行核验 SHA-256，检出同长度替换，不等于自动阻止所有替换文件导出。
- 实际渲染时长按 30 FPS 量化；若短于实际配音则明确报错，不静默截断。可点击「恢复配音时长」或延长镜头。
- 各段先归一化为 48 kHz 双声道 PCM、补齐到对应镜头长度，再拼接完整 PCM 音轨，最终统一编码 AAC；避免逐段 AAC 编码引入累积偏移。
- BGM 两种模式均可循环混入，按音量设置处理。全片与按镜配音不叠加。
- **按镜实际时长匹配不等于语音对齐。** `0.5.0` 已支持手动字幕时间轴及独立 SRT 导出，旧项目仍整镜显示；采用／移除配音或切模式后，已有时间轴需检查确认，不会自动拉伸或裁切。没有自动语音对齐、ASR、逐词时间戳、ASS 或音频裁切／淡化。见 [字幕说明](CAPTIONS.md)。

## 批量、失败与费用

- 每批最多 100 个唯一镜头，串行每镜一次请求；范围内任一字幕为空时先提示，不启动批量。
- “缺失或过期”仅按配音引用与当前文字判断，不检查磁盘文件，也不因音色／语速改变自动重生成；缺文件可单镜重生成。
- 普通服务错误、非法 WAV 或超时记录为单镜失败，后续可继续；认证失败、限流或落盘失败停止后续调用。
- 取消终止当前网络读取，不启动后续镜头；保留已成功候选，不自动重试。超时覆盖请求与响应读取，并在落盘前后检查；取消／超时不保证服务端停止处理或计费。
- 保存草稿的准备阶段取消后不提交配音请求。每镜保留最新成功候选及最近一次失败；连续失败不覆盖成功，新成功替换同镜旧候选与失败。未采用候选不随项目恢复。
- 候选在批次返回后显示，不是每镜实时回传。成功候选需逐镜确认采用；重生成不自动覆盖原配音。
- 显示调用上限、成功／失败／未执行数及错误，不是账单。**暂无精确价格、实际用量、费用持久化或幂等重试保障。**重新生成需再次确认，可能重复计费。
- 配音、文本、生图及导出互斥，没有多任务队列。`0.6.0` 重启后保留任务／已完成文件记录并支持哈希核验，不自动回填候选或重发；逐镜登记失败保留成功文件、停止后续镜头。新增有生成原稿元数据的任务配音显式关联，需文字／实际时长匹配，旧配音缺原稿／音色时拒绝，见 [产物重新关联](产物重新关联.md) 与 [恢复说明](RECOVERY.md)。

## 文件与安全

- Key 用 Electron `safeStorage` 加密后原子写入独立 `speech-settings.json`，权限 `0600`；macOS 钥匙串保护的是加密密钥，不是直接保存明文 API Key 条目。不可用时拒绝保存／解密，不回退明文。
- 保存后 Key 不回显；留空保留，勾选可删除。更换基础地址必须重新输入或删除 Key，项目不包含服务地址或凭据。
- 仅确认生成时发送对应配音稿、模型、音色和语速，不上传独立字幕时间轴、图片、音频或整份改写历史；不跟随重定向，不透传服务错误体及底层异常。
- 主进程剥离 WAV 额外元数据，随机文件名、临时文件原子落盘到用户数据目录 `generated-speech/`，文件权限 `0600`。
- 项目保存已采用片段的路径、文字、模型、音色、语速、实际时长和生成时间；不包含音频本体。旧项目无新增字段仍可打开，默认全片模式。
- 丢弃候选、替换／移除配音、新建／关闭项目均不删除音频文件；未采用候选不随项目恢复。暂无配音版本切回、存储配额、自动清理或素材打包，清理前确认其他项目未引用。
- 这些限制不是完整媒体安全审计，不能替代真实供应商与正式安装包验收。

## 已执行验证

```bash
npm run test:speech
npm run test:speech-desktop
```

- 12 项协议／文件测试：参数、采样时长、元数据剥离、损坏与格式限制、落盘权限、请求参数、不泄漏错误、部分失败、认证／限流停止、取消／超时、采用及配置隔离。
- 4 项真实 FFmpeg 导出测试：最终 AAC 解码检查 440／880 Hz 音调顺序、静音间隙、尾部补齐、单双声道与采样率归一化、BGM 音量、模式互斥、过期／缺失／损坏／时长／截断保护及取消清理。
- 真实 Electron：配置不自动联网、确认／试听解码和播放、候选采用／丢弃／过期、实际时长同步、模式切换、批量部分失败、保存重开、最终 MP4 音轨、取消保留成功、任务互斥、移除、新项目隔离和删除 Key。
- 桌面模拟成片为 5.133333 秒、720×1280、H.264、yuv420p、AAC、30 FPS；截图及可重开项目保存在 `artifacts/speech-smoke.*`。
- 本轮 `npm run test:hardening` 与 `npm run test:hardening-desktop` 另验证准备期取消零请求、成功 WAV 后连续失败仍可试听／采用、新成功清除旧失败及跨项目隔离；详细结果见 [功能验证记录](FEATURES.md)。

全部生成请求仅访问本机模拟服务，返回的是测试音调，**不是实际人声或模型质量验收**。单元加密为注入 codec，桌面 `safeStorage` 为替身。真实供应商协议、音色效果、费用、钥匙串系统授权／重启解密、长任务与正式安装包仍需单独验收。
