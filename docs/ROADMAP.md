# 实施范围与后续路线

> 本文维护阶段与顺序；完整功能清单、当前实现状态及验收记录统一维护在 [FEATURES.md](FEATURES.md)，不以本路线图中的规划描述代表已经实现。

## 已确定的产品约束

- 首要平台是 Intel Mac（x64）。
- 第一阶段直接生成 MP4，不处理剪映草稿格式。
- 逐步覆盖故事解说、小说推文、知识解说、音乐 MV、HTML 动画和混剪。
- 独立实现，不复制参考产品资源，不实现授权绕过。

## 阶段一：本地出片闭环（已完成开发验收）

目标：不需要账号、模型 API Key 或联网服务，就能通过真实桌面客户端完成一次视频制作。

验收项：

1. Intel Mac 启动 Electron，预加载桥可用，渲染页面无 Node.js 权限。
2. 图片和音频经过文件选择器导入；分镜可以编辑、排序和删除。
3. 保存项目后可重开，缺失图片明确显示并可重新关联。
4. 导出横屏／竖屏 MP4，视频为 H.264、音频为 AAC。
5. 字幕烧录、运镜、淡入淡出、配音补静音／截断、音乐循环均走真实媒体处理。
6. 取消和错误路径清理本任务临时目录，不破坏已有目标文件。
7. 保留演示视频、截图以及可重复执行的局部测试。

不将当前规则拆分称为 AI 分镜，不将静态分镜预览称为成片预览，不将手动重导出称为断点续跑。

## 阶段二：AI 生成与任务恢复

当前已实现文本配置、改写／分镜候选与采用、改写历史；`0.3.0` 增加图片配置、生图候选与版本切换；`0.4.0` 增加配音配置、音色／语速、按镜生成、试听采用、实际时长及模式。`0.5.0` 增加每镜多条手动字幕、起止编辑、按帧预览、按时烧录与 SRT。`0.6.0` 增加独立自动草稿、启动恢复／放弃、关闭刷新、任务及逐镜产物落盘与哈希核验，通过真实 SIGKILL 重启／在途保存验收，并回归受影响流程。**字幕估算不是语音对齐，恢复不是自动续跑；真实模型与真实 macOS 钥匙串尚未验收**，实际费用、完整事件日志、幂等／自动复用及镜头缓存续渲染仍待实现。逐项状态以 FEATURES 为准。

- 文本：先接一类 OpenAI 兼容协议，提供连接测试、超时与结构化输出校验。
- 图片：先实现 OpenAI 兼容生成接口与模拟验收，再在用户准备真实调用时联调正式服务；已支持按镜生成、版本切换与显式重新生成，不自动重试。仅支持 Base64／同源图片 URL。
- 配音：先实现兼容 `/audio/speech` 的完整 PCM16 WAV 协议，已支持按镜保存、试听采用与采样数时长反推；不自动重试。真实供应商、其他格式／异步协议和计费需另行验收。
- 密钥：使用系统安全存储，安全存储不可用时明确报错，不静默写入明文配置。
- 成本：已展示预计调用上限且不自动重试；持久化幂等与实际用量／费用仍待实现，用户手动重发可能重复计费。
- 状态：已记录任务初始阶段、逐镜结果及终态，成功产物保留大小／SHA-256；完整生成／下载事件时间线另行实现。
- 恢复：已恢复独立草稿、展示中断任务并可核验本地文件；新增图片／有原稿配音的预览、选镜及显式关联，采用前复核，不自动回填或联网续跑。后续参数指纹、幂等与镜头缓存仍需另行实现，不能仅凭进度百分比／文件名继续。见 [恢复说明](RECOVERY.md) 与 [产物重新关联](产物重新关联.md)。当前使用原子 JSON，无新增数据库依赖；大规模队列再评估 SQLite。
- 字幕：本地手动句级时间轴及 SRT 导出已验证，保留无效草稿与依据过期保护；自动语音对齐、SRT 导入／ASS、音频裁切／淡化需后续单独确认，ASR 另行选型。见 [字幕说明](CAPTIONS.md)。

审查后的可靠性修复及 [素材统一检查／导出预检](素材检查.md) 已交付。2026-11-13 新增产物显式关联及 [长文分段与覆盖检查](长文分段与覆盖检查.md)：本地计划预览、确认调用上限、串行首错停止、逐段候选检查点与重开补跑、编号映射异常阻止采用；不自动联网重发或静默改素材关联。覆盖映射不证明语义忠实，跨段不共享正文，真实模型／费用／钥匙串仍未验收；未扩展自动语音对齐、幂等或续渲染，也不因此授权下一阶段。

选择先实现窄协议并模拟验证，是为了在不提前索取 Key 或付费调用的前提下验证链路、控制错误面；备选是同时支持大量平台，但适配维护、计费差异和排障成本显著更高。Cookie 类接入不作为默认主干依赖。

## 阶段三：扩展工作流

- 音乐 MV：导入音乐／歌词、歌词对齐、按段生成画面、节奏与镜头编辑。
- HTML 动画：白名单模板、隔离渲染进程、稳定帧率采集；不直接执行不可信生成代码。
- 混剪：素材入库、裁切、视频时长与音频策略、基础转场、版权来源记录。
- 辅助能力：角色素材、风格与提示词模板、声音管理。

这些功能共用项目结构与媒体合成层，但并非只是新增菜单；每类需要单独定义验收样例。

## 发布前关卡

- 已在 Intel Mac 构建未签名 x64 DMG，并完成完整性／包内文件检查；用户安装后，独立档案的安装版导入、保存退出重开、素材检查、SRT／720p MP4 及包内 Sharp／FFmpeg 实际运行通过。系统断网、干净环境／不同系统版本、原生对话框手工交互和 Gatekeeper 仍待验收，不将本地工作流通过等同正式分发通过。见 [安装包构建与验收](安装包构建与验收.md)。
- 完成依赖及二进制许可证清单、开发者签名和 Apple 公证。
- 验证长视频、磁盘不足、损坏素材、重复操作及程序退出的资源清理。
- 引入网络服务后逐项记录发送的数据、服务域名、费用和隐私边界。
- 如未来恢复剪映草稿功能，必须重新确认目标剪映版本并做真实导入验收。
