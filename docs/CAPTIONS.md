# 字幕时间轴与 SRT

`0.5.0` 提供本地手动时间轴、按时烧录 MP4 和独立 SRT 导出。不调用模型、不接 ASR；**初始时间估算仅按文字长度分配，不是真实语音对齐**。

## 使用

1. 保存项目，重启新版桌面客户端；主进程及 preload 不能只靠前端热更新。
2. 选择分镜，在右侧「字幕时间轴」点击「估算并启用时间轴」。旧项目默认保留整镜字幕，不自动转换。
3. 每镜最多 20 条；逐条编辑文字、开始及结束秒数，可添加、删除、重新估算。重新估算会提示替换原草稿。
4. 「配音稿／旧模式整镜字幕」仍是配音输入。启用时间轴后，字幕措辞独立编辑，不会让配音文字过期；反之修改配音稿、采用／移除配音或切换配音模式，会使时间轴依据过期。
5. 请加载已采用配音试听，手动核对时间，再点击「检查并确认时间轴」。该按钮只检查数据，不听音频、不自动对齐、不裁掉越界条目。依据过期时先修好时间再确认。
6. 拖动「字幕预览帧」查看该帧字幕或间隙。游标只预览静态分镜，不播放／联动音频，不模拟运镜、转场或精确字体排版。
7. 保存项目可保留未修好的草稿，重开继续编辑。文字为空、倒置、重叠、越界、不足一帧或依据过期时，不显示误导性的预览字幕，并阻止烧录导出及 SRT。
8. 「恢复整镜字幕」会确认删除时间轴，重新整镜显示配音稿；时间轴中删除全部条目则表示本镜无字幕，不回退到配音稿。
9. 开启「烧录字幕」后导出 MP4；也可在「声音与输出」点击「导出 SRT 字幕」。关闭烧录时 MP4 忽略时间轴的跨字段错误，SRT 仍独立校验；SRT 不要求图片／音频文件存在，也不验证磁盘音频。

## 时间规则

- 时间以镜头内秒数保存；项目保留源稿、配音片段 ID 和配音模式供过期检查。切镜头顺序时，字幕随镜头移动。
- 新时间轴在全片模式下上限为镜头渲染时长；按镜模式下为镜头渲染时长与已采用配音实际时长中较小者。全片音频没有逐镜定位，本轮不分析其内容。
- MP4 与 SRT 使用相同的 30 FPS 整数帧，区间为 `[startFrame, endFrame)`：开始向上、结束向下量化，避免字幕超出填写区间。量化后不足一帧会报错；相邻区间可以共用边界，但不重复显示上一条。
- 起止输入支持小数；分镜长度按 `round(duration × 30)` 帧，跨镜全局偏移逐镜累加该帧数，而不是直接累加未经量化的秒数。SRT 再将帧换算为最近毫秒。
- 旧整镜字幕为兼容保留整个镜头显示，**不应用新时间轴的配音上限**。按镜 MP4 仍校验真实 WAV，短于实际配音的镜头不会被静默截断。
- 每条最多 180 字符；检查按开始时间排序，不改变草稿的显示顺序。不自动拉伸／压缩旧时间轴；新音频更短时需手动修复，或明确重新估算。

## 实现选择与限制

继续用 Sharp 生成透明字幕图片，裁去透明区域，FFmpeg 按整数帧启用叠加；每条图片为单帧输入，避免循环解码多幅完整画布。没有新增依赖。备选 libass 样式能力更丰富，但当前随附 FFmpeg 无 `subtitles` 滤镜；ASR 可提供自动时间戳，但需另选识别方案并验证准确度，本轮不引入。

字幕仍是固定字体、大小和位置的图片，没有字体样式编辑、长字幕完整安全区保证、独立 MP4 字幕轨、逐字高亮、波形、自动语音对齐、SRT 导入或 ASS 读写。字幕中空行及控制字符会规范化；SRT 对 `&<>` 转义以避免当作播放器标签，部分纯文本播放器可能直接显示实体字符，兼容性不能视为所有播放器均已验收。

SRT 先完整校验，再在目标目录写临时文件（`0600`）并重命名；失败不覆盖已有目标，临时文件会清理。MP4 沿用完整输出后才替换目标的策略。素材仍以绝对路径引用，不随项目打包；同长度音频被外部替换目前没有内容哈希检测。

## 实际验证（2026-11-12）

- `npm run test:captions`：10 项核心测试、4 项真实 FFmpeg 测试。覆盖旧项目、帧边界、估算正文保留／20 条上限、过期／越界／重叠／空条、SRT 格式及原子失败保护；逐帧检查出现／消失、间隙、相邻边界、跨镜偏移、20 条合成和关闭烧录。
- `scripts/smoke-captions.ts`（可复用 `npm run test:captions-desktop`）：真实 Electron 编辑／增删／按帧预览、无效草稿保存重开、切模式过期、更短配音采用后的过期／越界、检查确认、分镜排序、独立 SRT、MP4、整镜恢复及空时间轴。
- 桌面产物 `artifacts/captions-smoke.*`；MP4 为 2 秒、720×1280、H.264、yuv420p、AAC、30 FPS。配音更换仅访问本机音调模拟服务，safeStorage 为替身，不证明真实模型、实际计费或系统钥匙串可用。
- 相关主进程、preload、渲染及新增测试入口的严格 TypeScript 与变更文件 ESLint 已检查；未全量构建或打包安装包。完整状态与回归记录见 [FEATURES.md](FEATURES.md)。
