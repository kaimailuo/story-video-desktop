# Storybound 1.27.0 功能清单

整理日期：2026-11-12。

本文归档原安装包及官网研究结果，**不记录自研客户端完成状态，不增加已承诺需求**。自研状态以 [功能总清单](../FEATURES.md) 为准，原产品结构见 [架构图](架构图.md)，来源与覆盖见 [证据与限制](证据与限制.md)。

## 一、阅读口径

- **静态**：存在实际代码、调用参数、状态操作或原生实现证据，不只是 UI 名称；不是运行成功证明。
- **官网**：公开文档声明，不能替代包内或运行证据。
- **受限**：受平台、权益、供应商、配置、禁用开关或额外资源约束。
- **未证实**：在已分析范围没有足够证据，不能把有界搜索说成全产品绝对不存在。
- 下表编号以 `SB-` 开头，仅用于本研究定位；与自研 `docs/FEATURES.md` 的编号没有映射或完成状态继承关系。
- 会员门槛是本包可见逻辑，价格／资格及当前服务可用性可能由云端改变。没有开展付费、账户或生成验收。

| SB-094 | 风格化转绘 | 素描／水墨／工笔等、自定义风格、缓存／断点／失败回原图 | 公共流程与官网；逐引擎效果未验收 |
| SB-095 | 画图四种模式 | 文生图、参考图（最多 3 张）、智能规划、封面海报 | 静态 |
| SB-096 | 绘图队列 | 风格×比例组合、取消／重试／参数复用／继续参考编辑／批量下载 | 静态；智能规划只用所选比例首项 |
| SB-097 | 实验室持久化 | `playground_jobs`、图片／视频本地保存、记录删除 | 静态；不是无历史沙盒 |
| SB-098 | 查询与视频 | 部分上游任务查回、RunningHub 图生视频，前端同时限制 2 条 | 静态＋受限 |
| SB-099 | 配音实验室 | 最多 10000 字符、音色／语速、分段进度、试听、MP3 另存与打开目录 | 静态；合成依赖外部 TTS |
| SB-100 | 配音实验室历史 | 扫描 MP3＋`voicelab_manifest_v1` 元数据 | 静态；清单丢失只能部分恢复 |

素材处理不能消除版权／肖像权责任；实验室“不扣软件积分”不等于供应商免费。重试可能读取当前配置，不保证锁定首轮引擎。

| 编号 | 功能 | 范围与边界 | 证据口径 |
|---|---|---|---|
| SB-109 | 市场浏览 | 模板／风格／封面、搜索／排序，真实 `/v1/market/*` 请求 | 静态；云端开放状态待核 |

## 十七、不能标记为已支持的事项

| 事项 | 本轮结论 |
|---|---|
| 独立小说推文系统 | 未找到章节管理、长篇角色记忆等证据；通用故事不能等同小说系统 |
| 完整本地视频混剪系统 | 未证实；MV 混剪入口禁用，不能凭遗留函数认定开放 |
| 所有模式直出 MP4 | 不成立；HTML 链证据明确，普通图文／MV 主要输出草稿 |
| macOS 剪映自动导出 | 附带控制源码不足以证明依赖与完整闭环 |
| Mac 橱窗自动采集 | 自动化前端限定 Windows；Mac 手动台账应独立描述 |
| Intel 原包兼容 | 本次包为 ARM64，不能替代 x64 包和 Intel 实机验证 |
| 内置多平台自动发布 | 外部工具推荐不等于内置发布系统 |
| 全天候后台／云端调度 | 多处为应用内轮询；独立服务未证实 |
| 零重复付费／严格幂等恢复 | 有查回与文件检查，不足以证明绝对保证 |
| 向量检索／RAG／独立知识平台 | 文件型工作台与知识科普视频有证据，不能扩大认定 |
