# 素材统一检查与导出前预检

## 如何使用

1. 保存项目并重启新版桌面客户端；主进程和 preload 变更不能只靠前端热更新。
2. 在「声音与输出」上方找到「素材统一检查」，点击「检查项目素材」。无需配置模型或 Key，不发送生成请求。
3. 查看阻塞、警告和明细；「定位分镜」可选中对应镜头，并滚动到分镜设置。文件路径仅在本机显示。
4. 用既有导入／替换、移除配音、恢复时长或字幕编辑功能处理问题，再重新检查。面板不会自动寻找、修复、关联或删除文件。
5. 点击「导出 MP4」时，即使未手动检查，也会由主进程重新检查。缺图不再只是禁用按钮，而会列出对应分镜。存在阻塞时，不打开导出位置选择器、不登记渲染任务、不启动渲染、不替换已有成片。

## 检查范围

| 对象 | 检查与导出规则 |
| --- | --- |
| 当前分镜图片 | 必须存在；绝对路径、支持的扩展名、普通可读文件；解码静态 PNG／JPEG／WebP，最多 8000 万像素。坏图／缺图阻止导出；不扫描历史图片版本或未采用候选 |
| 已采用按镜配音 | 与渲染共用 PCM16 WAV 校验、当前配音稿匹配、实际文件时长与记录一致、按 30 FPS 量化后的镜头不得短于配音。当前按镜模式下错误阻止导出；全片模式下仅警告 |
| 缺少按镜配音 | 按镜模式下警告，并沿用该镜静音规则；全片模式下跳过。没有自动生成配音 |
| 全片配音 | 已设置的文件进行真实完整音频解码；全片模式下错误阻止导出，按镜模式下仅警告。未设置不要求此音轨；原有补静音／截断规则不变 |
| 背景音乐 | 已设置即检查，即使音量为零也不忽略，因为现有混音仍读取该文件。错误阻止导出；未设置则跳过 |
| 字幕 | 启用烧录时，逐镜使用现有字幕编译规则检查；关闭烧录不因此拒绝字幕草稿。独立 SRT 仍只检查字幕，不要求图片或音频存在 |

普通音频支持 MP3／WAV／M4A／AAC／FLAC／OGG，由随附 FFmpeg 强制对应本地解复用器、完整解码至空输出，不生成音频文件，不把伪装播放列表交给自动协议识别。检测到错误、无有效音频或超时均不算通过；不是所有损坏、编码器兼容性或恶意媒体安全性的保证。

## 结果、资源与退出

- 报告只保留当前会话内最近一次结果；项目编辑后标记过期，定位按钮停用；新建、打开或恢复其他项目后不展示旧报告。
- 外部移动／改写文件不会自动刷新报告；每次检查重新读磁盘。同一次扫描只对重复路径的图片／普通音频去重，不跨扫描缓存。
- 图片解码单项设置 10 秒处理超时；普通音频单项最多 30 秒，整次扫描约两分钟预算。超过预算的未确认项明确报错／警告，不假装通过。网络挂载盘／底层文件系统卡死不在硬实时保证范围。
- 检查串行运行，与 AI／导出互斥，检查期间暂时锁定编辑。没有检查进度百分比或独立取消按钮；正常关闭窗口可选择继续，或取消并退出。FFmpeg 子进程支持中断；Sharp 当前操作需完成／超时后才能结束。
- 导出位置选择之前检查一次，真正渲染入口再独立检查一次，防止绕过 UI 或把旧报告当授权。这会额外增加 I/O，长音频可能需要转换／缩短后再检查。
- 报告不是文件锁、内容指纹或备份，不保证检查之后文件不变；不承诺阻止所有外部替换、多实例竞态或完整安全审计。任务面板的 SHA-256 核验仍是另一项能力，见 [恢复说明](RECOVERY.md)。

## 实现选择与验证

复用 Sharp、现有 WAV 校验及随附 FFmpeg，检查与渲染共用规则，不新增系统依赖。备选 FFprobe 更适合快速读取元信息，但只看元信息不能证明可完整解码，且需要独立打包／路径验收；仅检查文件存在最快，但会把损坏问题留到渲染后期。
