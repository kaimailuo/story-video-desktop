# Intel Mac 安装包构建与验收

本说明区分“构建成功”“包内检查通过”和“从安装后的客户端完成出片”。只有最后一项实际执行后，才可记录安装使用验收通过。功能状态以 [功能总清单](FEATURES.md) 的 PF-05／06／07／09 为准。

## 本地测试包

在客户端项目目录执行：

```bash
CSC_IDENTITY_AUTO_DISCOVERY=false npm run package:mac
```

该命令执行本客户端的 TypeScript 主进程编译、Vite 生产构建和 electron-builder x64 DMG 打包；不是全量测试。输出位于 `release/`，不上传或安装应用。首次打包可能联网下载 Electron 或打包资源，不调用模型服务。环境变量仅关闭本次签名身份自动发现，不关闭 macOS 安全防护。

当前未配置 Developer ID 签名、Apple 公证或自定义应用图标，仅用于本地测试，不是可公开分发的正式版本。打包需要写入派生产物目录；若已有交付包，先备份／改输出目录，避免重新打包覆盖。

## 构建前检查

- 目标为 Intel Mac x64，不是 Apple Silicon 原生包或通用包。
- 核对 Electron、FFmpeg、Sharp 及 libvips 的 x64 架构、依赖可用性和磁盘空间。
- 渲染入口使用相对资源路径；正式应用忽略开发服务器环境变量，从包内加载页面。
- `ffmpeg-static`、Sharp 及 `@img` 原生依赖需随包，二进制放在 `app.asar.unpacked`；不能把本机 Homebrew 工具存在当作安装包自带能力的证据。
- 当前本机 Electron 45.3.0 的运行时声明最低 macOS 13.0；这不是对所有 macOS 13 设备的实测承诺。

## 安装前的包内检查

构建完成后，应核对 DMG 完整性、体积及 SHA-256，检查 `.app` 的版本／架构、主进程／preload／生产页面和原生依赖是否实际进入包内。不得将这些检查称为已安装验收或完整恶意代码扫描。

生产包不应包含测试脚本、演示验收档案、真实用户草稿或模型凭据。依赖包自己的许可证／声明文件应保留；仅检查目录不等于完成许可证义务审查。

## 安装与使用验收清单（手工／其他环境仍需单独验收）

1. 保存当前工作，退出开发版和旧安装版；如“应用程序”中已有同名应用，先确认版本及备份，不直接覆盖。
2. 打开可信的本地 DMG，将“映序”拖入“应用程序”；退出磁盘映像后，从“应用程序”启动，避免把直接运行 DMG 中的应用当成已安装。
3. 不启动 Vite 或开发进程，不配置模型，载入本地演示，确认中文界面及图片显示。
4. 导入自己的图片／音频，保存项目、退出、重新启动并打开项目，检查素材路径及草稿恢复行为。
5. 检查素材并导出 MP4，核对画面、中文字幕、时长及声音；应确认使用包内 FFmpeg，而非系统路径回退。离线运行、干净环境和不同受支持 macOS 版本仍需分别验证。
6. 如 macOS 拦截未签名包，记录原始提示，先核对来源、签名与公证状态，不关闭 Gatekeeper、不移除安全属性来冒充发布验收通过。
7. 真实模型与钥匙串另行验收，Key 只在客户端输入；付费请求必须先确认，不因安装完成就自动测试。

安装版可能与开发版使用不同的用户数据目录；不要依赖应用名称推测数据自动迁移。用户数据、草稿及生成素材不属于安装包，保留原手动项目和素材，不自动清理或搬迁。
