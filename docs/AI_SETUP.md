# 文本 AI 配置与验证

## 当前支持范围

自 `0.2.0` 起支持 OpenAI 兼容的非流式 `POST /chat/completions`，`0.6.0` 增加本地长文分段：

- 主动连接测试。
- 文案改写：原文／结果对照，确认采用。
- 结构化分镜：字幕、画面描述、绘图提示词、建议时长和静态／推进运镜。
- 最近 100 条已采用改写的原文与结果，随项目保存。
- 超时、主动取消、认证／限流及格式错误提示。
- 本地预览长文分段、串行处理与来源编号检查，逐段候选可保存／重开后明确补跑。

文本面板不支持 Anthropic 原生协议、Responses API、自动选择模型、流式输出、配音或事实核验。`0.6.0` 记录任务及已校验文本结果 JSON，不从任务自动回填普通短文候选或重发；长文逐段候选另随项目／草稿保存。见 [恢复说明](RECOVERY.md)。图片与配音由独立面板提供，见 [图片 AI 配置与验证](IMAGE_SETUP.md)、[配音 AI 配置与验证](SPEECH_SETUP.md)。不同兼容服务对参数的支持可能不同，尚未完成真实服务验收。

## 配置流程

1. 保存当前项目，重启到新版客户端；开发模式运行 `npm run dev`。
2. 点击侧栏「文本模型设置」。
3. 填写 API **基础地址**，例如服务商给出的 `https://api.example.com/v1`；不要附加 `/chat/completions`、Key、查询参数或账号密码。
4. 填写服务商提供的准确模型标识，以及 5–180 秒超时。
5. 仅在客户端本机输入 Key，点击「保存模型设置」。输入框随后清空，不回显旧值。
6. 如需联调，点击「测试已保存配置」；客户端说明地址、模型和可能费用，经确认后只发送一次极短消息。

公网地址必须是 HTTPS。只有 `localhost`、`127.0.0.1` 和 `::1` 的本机测试地址可使用 HTTP。配置保存本身不发请求，不自动拉取模型清单。

留空 Key 表示保留原 Key；勾选「删除已保存的 Key」可删除密文。更换基础地址时，必须重新输入或删除 Key，防止无意将旧服务凭据发送给新服务。

## 使用流程

1. 输入文案并选择视频类别，可添加补充要求。
2. 短文点击「AI 改写文案」或「AI 生成分镜」，确认后只发送一次请求。超过本地单段预算会拒绝，应在下方预览分段、核对调用上限后确认处理，不自动重试。
3. 检查候选：生成并不会自动修改项目。采用改写后，原文进入改写记录；采用分镜一律确认现有编辑的替换影响，包括无媒体的手工字幕、提示词、时长和排序。可撤销最近一次分镜替换，仅本次会话有效，关闭／切换项目失效；不删除磁盘素材。
4. 文案或类别改变后，旧候选不能直接采用，应重新生成。
5. 采用分镜后，可逐镜修改画面描述、提示词、字幕和时长，再独立生成或导入图片、生成按镜配音或导入全片音频，之后导出 MP4。

改写不会自动同步已有分镜；如需要，请在采用改写后重新生成分镜。历史只记录已采用结果，不保存已丢弃候选、未完成请求或完整对话。超过 100 条时保留最近 100 条。

准备阶段会先保存独立草稿；此时取消，保存结束后不会再提交模型请求。提交后取消不保证服务端停止计费，取消未确认时请核对状态，不要盲目重复生成。

输入最多 30,000 UTF-16 字符；长文按分镜每段最多 600、改写最多 1200 字符本地规划，每段固定 `max_tokens: 4096`。首错停止，成功不重发，逐段候选随项目保存。来源编号检查能发现缺号／重复／越界／乱序，但不能证明模型实际保留含义；没有跨段共享正文或一致性保证。完整操作、超限保护与存储边界见 [长文分段与覆盖检查](长文分段与覆盖检查.md)。

## 密钥与隐私

- 主进程使用 Electron `safeStorage` 加密 Key；macOS 上，加密所用密钥由系统钥匙串保护。
- 用户数据目录的 `ai-settings.json` 记录地址、模型、超时和加密后的 Key，采用原子替换及 `0600` 文件权限；不是直接把 API Key 写成钥匙串条目。
- 系统加密不可用或失败时拒绝保存／解密 Key，不提供明文兜底。
- 获取设置只返回是否存在 Key，不解密回传给页面；项目 JSON 不包含模型配置或 Key。
- 改写／分镜仅发送当前文案（分段时仅本段）、类别、补充要求和应用预设的编辑指令；分段还发送段序号与原文单元编号，不发送图片、音频、其他段正文或整份历史。
- 请求不自动跟随重定向；不将服务端原始错误体或底层错误直接放入界面／日志，避免回显凭据。
- 取消或超时只中断客户端请求，**不能保证服务端停止计算或计费**。服务未报告 Token 用量时明确说明未知；报告用量也不是价格。
- 这些措施不等于完整安全审计；被恶意控制的操作系统／客户端进程不属于本阶段已解决的威胁。

首次使用真实安全存储时，macOS 可能要求系统授权。正常授权流程及后续版本的密钥读取仍需人工验收；不要通过关闭安全防护来替代验收。

## 已做与未做的验证

```bash
npm run test:ai
npm run test:ai-desktop
```

前者使用本机临时 HTTP 服务和注入的加密接口验证协议、格式、错误、超时／取消、密文文件和项目兼容；加密接口测试使用 Node.js AES-GCM，不代表系统钥匙串已验收。

后者启动真实 Electron，调用本机模拟 HTTP 服务。为了无人值守执行，它仅在测试进程中替换 `safeStorage`，验证 UI／IPC／配置与候选流程，不接触真实 API Key 或钥匙串授权。

**仍需人工验证：**真实模型输出质量和协议兼容、实际计费、macOS 系统授权、重启后的真实 Key 解密，以及正式签名安装包中的密钥可用性。没有这些结果，不应将模拟验收描述为真实服务接入成功。
